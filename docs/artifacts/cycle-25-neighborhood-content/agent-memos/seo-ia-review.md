## 3. Metadata plan (per city)

Driven by `buildMetaDescription(market)` in `src/app/markets/[slug]/page.tsx`. Pattern:

```
Title: "${market.name} Luxury Real Estate | Mia Sanabria"
Description: "<first sentence of aeoAnswer, trimmed> Mia Sanabria, REALTOR® with LPT Realty."
Canonical: "https://miasanabria.com/markets/<slug>/"
OG title/desc: same
OG image: https://miasanabria.com/og-markets/<slug>.jpg (1200x630, generated by sharp)
```

Each city's `aeoAnswer` is written to start with a sentence that contains the city name + geographic anchor (e.g., "Deerfield Beach is a northeastern Broward city..."), so the auto-generated meta-description always frames the city correctly within the 140-160 char target.

## 6. Schema / structured data

`[slug]/page.tsx` already emits:

- `RealEstateAgentSchema` — Mia + LPT, unchanged
- `PlaceSchema` — `name`, `description`, `region: "FL"`, `county`, `latitude`, `longitude`
