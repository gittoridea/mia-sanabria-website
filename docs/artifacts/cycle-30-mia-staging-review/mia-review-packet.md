## How to flag your decisions

For everything you review, drop it into one of four buckets:

| Bucket | Means |
|---|---|
| **🛑 Must change before launch** | This cannot go live as-is. Tone wrong, fact wrong, missing something critical. |
| **⚠️ Prefer to change before launch** | Strong preference, but not a blocker if we run out of time. |
| **✅ Okay for v1** | Acceptable for launch. We can polish later. |
| **📅 Post-launch** | Worth doing eventually — not urgent. |

A simple way: write the URL, the bucket, and one sentence on what to change.

Example:

> `/markets/weston/` → ⚠️ Prefer to change before launch. The intro sentence reads too generic — I'd say "Weston is where families with horses and equestrian centers go" instead.
