## Hard constraints (must hold before any testimonial is published)

1. **Exact text — no paraphrase.** Direct quotes only. Capture the review verbatim, character-for-character.
2. **Attribution rules:**
   - Reviewer first name OR first name + last initial is the minimum on-site attribution.
   - Reviewer full name only with explicit reviewer permission (FCC/FTC + Florida defamation guardrails).
   - Date of review.
3. **No platform endorsement implication.** Source attribution language must NOT imply Facebook or Realtor.com endorses Mia. Acceptable phrasing example: *"From a Facebook review by [Name], [Date]."* Unacceptable: *"As featured on Facebook reviews"* or any "as seen on" framing (banned per project `CLAUDE.md` honesty contracts).
4. **No editorialization.** No "Mia Sanabria's clients say…" framing without the underlying quoted text supporting it word-for-word.
5. **Permission state:**
   - Public reviews on Facebook / Realtor.com profile are public statements, but **re-publishing on Mia's commercial site is a different use-case**. Counsel guidance recommended for any review reused in marketing where reviewer last name is shown.
   - Default: re-publish using first name + last initial unless reviewer is given a permission opt-in.
